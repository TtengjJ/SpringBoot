# 🚀 Spring Boot官方指南学习代码库  

**本仓库是 [Spring官方指南](https://spring.io/guides) 的完整代码实现，旨在通过实战代码帮助开发者快速掌握Spring Boot核心技术。**  
当前已覆盖 **60+ 官方指南**，包含基础开发、数据处理、安全认证、微服务架构等模块，代码均通过测试并附详细注释，持续更新中！  


## 🌟 项目亮点  
- **全场景覆盖**：从基础的REST API、表单处理到高级的微服务注册发现、Kubernetes部署，一站式学习。  
- **学习友好型代码**：每个模块包含独立`README`，标注关键配置（如`application.properties`）和核心逻辑注释。  
- **技术栈前沿**：基于Spring Boot 3.x和Java 17，集成最新技术（如Reactive编程、GraphQL、Observability）。  
- **实战可运行**：提供Postman测试脚本和前端页面示例，部分模块支持Docker一键部署。  
- **持续维护**：每周新增指南或优化代码，欢迎提交Issue或PR贡献内容！  


## 📚 目录结构  
按官方指南分类组织，以下为部分模块示例：  

### 1. 基础开发  
- [构建RESTful Web服务](https://spring.io/guides/gs/rest-service/)  
  - 代码路径：`/rest-service`  
  - 技术点：Spring MVC、JSON序列化、HTTP方法处理  
- [Spring Boot入门](https://spring.io/guides/gs/spring-boot/)  
  - 代码路径：`/spring-boot-basic`  
  - 技术点：自动配置、Starter依赖、Actuator监控  

### 2. 数据访问  
- [JPA与Hibernate](https://spring.io/guides/gs/accessing-data-jpa/)  
  - 代码路径：`/data-jpa`  
  - 技术点：Repository接口、Entity映射、事务管理  
- [MongoDB文档存储](https://spring.io/guides/gs/accessing-data-mongodb/)  
  - 代码路径：`/data-mongodb`  
  - 技术点：Reactive MongoDB、自定义查询  

### 3. 微服务与云原生  
- [Eureka服务注册与发现](https://spring.io/guides/gs/service-registration-and-discovery/)  
  - 代码路径：`/microservices-eureka`  
  - 技术点：Spring Cloud Netflix、客户端负载均衡  
- [Docker化部署](https://spring.io/guides/gs/spring-boot-docker/)  
  - 代码路径：`/deployment-docker`  
  - 技术点：Dockerfile编写、Maven/Gradle插件
